# Світло Дали

Збірка Minecraft для своїх: Create з потягами й дирижаблями, українська кухня, самогон і енергетики, мінні поля, Нова Пошта, бабуся Галя на базарі, ТЦК з перевіркою документів і книга квестів з жартами про сучасну Україну.

**Minecraft 1.21.1 · NeoForge 21.1.250 · 71 мод · версія 0.5**

Збірка оновлюється сама: лаунчер при кожному запуску звіряється з цим репозиторієм і докачує лише змінене ([packwiz](https://packwiz.infra.link/)).

## Як грати

1. Встанови [Prism Launcher](https://prismlauncher.org).
2. Візьми в Андрія архів збірки (`SvitloDaly.zip`, ~100 КБ) і імпортуй: «Додати екземпляр» → «Імпорт».
3. Запускай. Перший старт сам скачає всі моди (кілька хвилин), далі лише оновлення.

Адресу сервера питай в Андрія.

## Що всередині

| Папка | Що там |
|---|---|
| `mods/` | Посилання на моди (Modrinth / CurseForge) з контрольними сумами. Самих модів тут немає. |
| `kubejs/` | Наш контент: предмети, рецепти, механіки (зима, штрафи, банкомат, ТЦК, бабуся), структури, текстури, музика меню. |
| `config/ftbquests/` | Книга квестів. |
| `config/` | Ще кілька наших налаштувань модів. |
| `CHANGELOG.txt` | Журнал змін. |
| `tools/` | Службовий скрипт, що перераховує `index.toml`. |
